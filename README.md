# VK chat stats bot

Бот живёт в одной беседе VK, пассивно логирует все сообщения в SQLite и по командам отдаёт статистику. Плюс поздравления с «вехами» (круглые числа сообщений, годовщина чата).

## Команды

| Команда | Что делает |
|---|---|
| `/я`, `/me` | Своя карточка активности одним PNG: графики (сообщения в неделю, накопительный итог, по часам, по дням недели) и сводка в шапке (streak, средняя длина сообщения) |
| `/ты`, `/you` | Ответом на чужое сообщение — карточка того человека |
| `/мы`, `/we` | Ответом на чужое сообщение — сравнение тебя и автора: по две серии в каждой панели |
| `/чат`, `/chat` | Та же карточка по всей беседе |
| `/все`, `/all` | Рейтинг чата: график-гонка (накопительные линии топ-10) + текстом все места с эмодзи (🥇🥈🥉, ⚡ для 4–5), числом сообщений и датой, когда человек занял место и кого обошёл (💎 — на месте с самого начала) |
| `/ping` | Проверка, что бот жив (ответ «pong») |
| `/help`, `/помощь` | Список команд |

Английские варианты команд (`/me`, `/you`, `/we`, `/chat`, `/all`) рисуют подписи на картинке по-английски, русские — по-русски.

После любой команды статистики можно указать период в скобках: `(дата-дата)`, `(дата-)` или `(дата)` — от даты до конца, `(-дата)` или `(Х-дата)` — от начала до даты. Форматы даты: `дд/мм/гггг`, `дд.мм.гг`, `ддммгггг` и т.п. Пример: `/я (01.01.24-30.06.24)`. Streak при заданном конце периода считается относительно него.

## Установка

```bash
python -m venv venv
venv/bin/pip install -r requirements.txt      # Windows: venv\Scripts\pip
cp .env.example .env                          # вписать VK_TOKEN
```

Требования к сообществу VK (настраивается руками в интерфейсе VK):
- сообщения сообщества включены, Long Poll включён, версия API 5.199+;
- в «Настройках для бота» разрешено добавление в беседы;
- бот приглашён в беседу с доступом **ко всей переписке** (не «только упоминания»).

Python 3.11+. Проверено на 3.14; если `pip install vkbottle` на свежем Python падает — взять venv на 3.12.

## Импорт истории

Положить выгрузку чата в `data/export.txt` (UTF-8), затем:

```bash
python scripts/import_history.py
```

Скрипт печатает сводку (заголовков / служебных / импортировано / дубликатов). Идемпотентен: повторный запуск ничего не задублирует (`UNIQUE(cmid)`). Служебные события (`Действие "..."`) пропускаются.

## Запуск

```bash
python -m bot.main
```

Проверка после запуска: отправить сообщение в беседу — оно должно появиться в `messages` (`sqlite3 data/stats.db "SELECT COUNT(*) FROM messages"`) и учитываться в следующем `/я`.

## Тесты

```bash
python test_parsing.py
```

Проверяет парсер выгрузки, идемпотентность импорта и запросы статистики на встроенной фикстуре.

## Деплой на VPS (systemd)

```bash
sudo useradd -r -m -d /opt/vkstats vkstats
sudo -u vkstats git clone <repo> /opt/vkstats   # или rsync
cd /opt/vkstats
sudo -u vkstats python3 -m venv venv
sudo -u vkstats venv/bin/pip install -r requirements.txt
sudo -u vkstats cp .env.example .env            # вписать VK_TOKEN
sudo -u vkstats venv/bin/python scripts/import_history.py   # один раз
sudo cp deploy/vkstats.service deploy/vkstats-notify.service /etc/systemd/system/
sudo systemctl enable --now vkstats
journalctl -u vkstats -f                        # логи
```

## Уведомления о падении на почту

Заполнить в `.env`: `SMTP_USER`, `SMTP_PASS` (для Gmail — пароль приложения, нужна 2FA: myaccount.google.com/apppasswords), опционально `NOTIFY_EMAIL`. Не заполнено — уведомления молча выключены.

Два слоя:
- крэш Python внутри бота — письмо с трейсбеком шлёт сам процесс перед выходом (работает и локально на Windows);
- юнит окончательно упал (10 стартов за 2 минуты, OOM и т.п.) — systemd дёргает `vkstats-notify.service`.

Кулдаун 15 минут между письмами. Проверка вручную: `python -m bot.notify` — должно прийти письмо.

`Restart=always` — Long Poll держит постоянное соединение, процесс должен жить 24/7.

Для CJK-ников (японские/китайские символы) на графиках нужен шрифт:
```bash
sudo apt install -y fonts-noto-cjk
sudo -u vkstats rm -rf /opt/vkstats/.cache/matplotlib   # сбросить кэш шрифтов
```

## Устройство

- `bot/parsing.py` — общая классификация сообщений (маркеры вложений, подсчёт слов); используется и импортёром, и живым ботом
- `bot/db.py` — схема и все SQL-запросы (aiosqlite); агрегаты не материализуются, прямые запросы по индексам укладываются в миллисекунды
- `bot/chart.py` — PNG-карточка активности (matplotlib + pandas), строится из timestamps в БД
- `bot/main.py` — VKBottle-бот: один catch-all обработчик сохраняет каждое сообщение, затем проверяет вехи и диспетчеризует команды
- `scripts/import_history.py` — одноразовый импорт выгрузки
- Время хранится как naive ISO 8601 в часовом поясе `BOT_TZ` (по умолчанию Europe/Moscow) — так же, как в выгрузке; сообщества хранятся с отрицательным `vk_id` и исключены из рейтингов
